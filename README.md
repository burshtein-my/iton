# AI-газета

Каждое утро GitHub запускает скрипт: он собирает свежие новости нейросетей США и Китая и популярные у гиков
публикации про расширения для Claude и Claude Code, Claude API отбирает важное и пишет заметки по-русски,
а скрипт верстает газету в PDF и присылает её на почту (и на принтер, если указан его адрес).

## Что где лежит

| Файл | Что в нём |
| --- | --- |
| `config.yaml` | Источники, модели Claude, пороги популярности, название газеты |
| `templates/style.css` | Оформление газеты: шрифты, цвета, размеры |
| `templates/newspaper.html` | Макет газеты |
| `templates/email.html` | Макет письма |
| `.github/workflows/gazeta.yml` | Расписание запуска (строка `cron`) |
| `state/state.json` | Память: номер выпуска и что уже было в газете. Руками не трогать |
| `main.py`, `gazeta/` | Код |
| `fonts/` | Шрифты PT Serif и PT Sans (лицензия OFL, файл `fonts/OFL.txt`) |

## Секреты (Settings → Secrets and variables → Actions)

| Имя | Обязательно | Что это |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | да | Ключ из console.anthropic.com |
| `GMAIL_ADDRESS` | да | Ваш адрес Gmail, с которого уходит газета |
| `GMAIL_APP_PASSWORD` | да | Пароль приложения Gmail (16 букв) |
| `MAIL_TO` | нет | Кому слать, через запятую. Если пусто — на `GMAIL_ADDRESS` |
| `PRINTER_EMAIL` | нет | Email-адрес принтера для автопечати |

## Запуск вручную

Вкладка **Actions** → **AI-газета** → **Run workflow**. Галочка «Только собрать и сверстать» — пробный запуск
без отправки писем; PDF можно скачать внизу страницы запуска, в разделе **Artifacts**.

Локально: `pip install -r requirements.txt`, затем `python main.py --demo` — пробный номер без интернета и API.
